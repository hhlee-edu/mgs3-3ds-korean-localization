### CPP 안내

**CPP(Circle Pad Pro)**는 오른쪽 스틱 조작을 추가해 주는 확장 기능.  
New 3DS 계열에서는 일명 **‘빨콩’(C-Stick)**이 이 역할을 합니다.
CPP 없이 『메탈 기어 솔리드 스네이크 이터 3D』를 플레이하면 원래의 독특한(?) 조작 방식을 제대로 체험할 수 있지만… 
**개인적으로는 추천하지 않습니다.**

> **권장 버전**
> - **구형 3DS / 2DS :** 1.0
> - **New 3DS 계열/ 에뮬레이터 :** 1.1
>
> 1.1에서는 **CPP를 강제로 활성화**하도록 적용했습니다.
>
> 에뮬레이터의 경우 CPP 활성화 과정에서 하드웨어 확인 단계가 정상적으로 끝나지 않아 **프리징 또는 강제 종료가 발생할 수 있습니다.**
>
> 세이브 데이터를 이용해 우회하는 방법도 있지만, 편의를 위해 New 3DS 실기, 에뮬용은 CPP를 바로 사용할 수 있도록 적용함(못끔).

**1.1 패치가 정상 적용되었다면 타이틀 화면에 `1.1`이 표시됩니다.**

플레이 시에는 **CPP/C-Stick 감도를 기본값보다 조금 낮춰서 사용하는 것을 추천합니다.**

## 🐍 이 버전을 만든 이유

번역 완성도가 많이 부족해 보일 수 있지만, 우선은 이 게임을 **3D**로 즐기고 싶은 욕심이 더 컸습니다.
대화 말투는 최대한 다듬었으나, 다소 품질이 떨어짐. 이게 지랄맞은 공간 부족 탓도 있고..암튼.. 

> **어색한 문장은 검수나 제보를 통해 계속 수정할 예정입니다.**

3DS판은 프레임도 낮고 여러모로 구리(?)지만 실기에서는 충분히 빛을 발합니다.
특히 초반, 툭 하고 던지는 **시가는 한번 쯤 3D로 꼭 보면 좋다 제군들**

## 🔧 패치 작업

흩어진 대사와 고정 슬롯, 한국어 글꼴, 169개 스테이지 자산, ExeFS·RomFS를 함께 손보고 매 빌드를 다시 풀어 전수 검증했습니다.
