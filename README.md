## 시작하기

Windows 패처를 실행하고, 복호화된 **clean USA 1.0 CCI** 하나를 창 안으로 끌어다 놓으세요.

| 만들 버전 | 추천 기기 | 포함 내용 |
|:---:|---|---|
| **1.0 한글판** | 구형 3DS · 2DS | 한국어 패치 · CPP 없음 |
| **1.1 한글판** | New 3DS · New 2DS · 에뮬레이터 | 공식 1.1 수정 · CPP 자동 활성화 |

> **구형 3DS·2DS라면 1.0을 권장합니다.** CPP 장치가 없어 1.1 패치가 사실상 필요하지 않습니다.

1.1은 타이틀 화면에 **`1.1`**이 표시되면 정상입니다. 에뮬레이터에서는 CPP 감도를 조금 낮춰 주세요.

Update CIA, 암호화 키, GodMode9 추출 파일은 필요하지 않습니다.

---

## 이 버전을 만든 이유

번역 완성도가 아직 부족해 보일 수 있지만, 이 게임을 실기의 3D로 즐기고 싶은 제작자의 욕심이 더 컸습니다. 대화 말투는 최대한 다듬었으며, 어색한 문장은 제보를 모아 계속 수정할 예정입니다.

3DS판은 프레임도 낮고 여러모로 거칠지만 실기에서는 충분히 빛을 발합니다.
특히 초반 영상에서 날아가는 **담뱃불을 3D로 보면 정말 멋집니다.**

---

## 패치 작업

흩어진 대사와 고정 슬롯, 한국어 글꼴, 169개 스테이지 자산, ExeFS·RomFS를 함께 손보고 매 빌드를 다시 풀어 전수 검증했습니다.
1.1은 clean 1.0에 binary delta를 적용해 공식 수정 내용을 복원한 뒤 한국어와 CPP 패치를 더합니다.

> 기존 Luma game patching이나 `/luma/titles/0004000000081E00/` 잔재가 있으면 이중 패치로 실행 문제가 생길 수 있습니다.
