### CPP 안내

**CPP(Circle Pad Pro)**는 확장 패드 개념. 신형 장치에는 빨콩 같은 게 있고 오른쪽 스틱 역할을 함.

CPP 없이 하면 진짜 조작의 신세계(?) 체험 가능한데 비추임.

> **구형 3DS·2DS라면 1.0 / 에뮬, 뉴다수에는 강제로 CPP를 활성화함. 왜냐하면 에뮬에서는 CPP를 켜는 과정에서 강제 종료 이슈 있음.**

1.1은 타이틀 화면에 **`1.1`**이 표시되면 정상입니다. 플레이 시 CPP 감도를 조금 낮추시는 걸 추천합니다.

## 🐍 이 버전을 만든 이유

번역 완성도가 많이 부족해 보일 수 있지만, 이 게임을 실기의 3D로 즐기고 싶은 욕심이 더 컸습니다.
대화 말투는 최대한 다듬었습니다.

> **어색한 문장은 제보를 통해 계속 수정할 예정입니다.**

3DS판은 프레임도 낮고 여러모로 구리(?)지만 실기에서는 충분히 빛을 발합니다.
특히 초반 영상에서 날아가는 **담뱃불을 3D로 꼭 보셔야겠죠?**

## 🔧 패치 작업

흩어진 대사와 고정 슬롯, 한국어 글꼴, 169개 스테이지 자산, ExeFS·RomFS를 함께 손보고 매 빌드를 다시 풀어 전수 검증했습니다.
1.1은 clean 1.0에 binary delta를 적용해 공식 수정 내용을 복원한 뒤 한국어와 CPP 패치를 더합니다.
