# Disk cleanup (2026-08-16)

Repo **160.51 GB → 24.22 GB**, 136.29 GB reclaimed, done in four verified stages.

Method for stages 2-4: **delete only files larger than 20 MB inside the approved
targets.** Directories and every smaller file stay in place, so the code, logs,
manifests and diffs that prove each experiment's conclusion are untouched — only
the regenerable bulk binaries go. A hard protect-list guarded the baseline and
golden inputs on every run.
